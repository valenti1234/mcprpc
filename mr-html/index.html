    How this connects to an MCP Router (mcprpc)

    This frontend is designed to connect directly to a registry + router setup: GET {REGISTRY_URL}/functions to discover tools and POST {ROUTER_URL}/call to invoke a tool. The call response is read as a streamed HTTP body, so any server using chunked transfer (including streamable-http) can be displayed incrementally via response.body.getReader().

    In mcprpc terms, the registry provides the function catalog (including JSON Schemas), and the router resolves and executes the selected function over MCP transports (stdio or streamable-http). To satisfy ACLs, you may need to provide roles/tenant in the context fields.
